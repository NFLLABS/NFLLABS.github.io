# NFL LABS

Site public : https://nfllabs.github.io

- Pointages NFL en direct (ESPN, directement dans le navigateur).
- Propositions de paris bet365 (paliers) et Mise-O-Jeu calculées par des règles, cotes et blessures.
- Ligue fantasy QFF (MFL 49625) : matchs, classement, équipes, agents libres.

Le robot `.github/workflows/maj.yml` roule `scripts/run_all.py` et publie `data/*.json`.
Pour le divertissement seulement. Joue de façon responsable, 18+.
